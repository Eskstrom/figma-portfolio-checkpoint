# Shuffle for Comfort Watching

**Independent Netflix feature concept**

[Original concept in Figma](https://www.figma.com/design/W1i2PizUUUvCtPx4EnxpFx/Sumukh-s-Space?node-id=653-53) · [Feature collection](https://eskstrom.github.io/?category=new-features#library)

## The problem and direction

Help a viewer choose a random episode from previously watched series when they want familiar entertainment without browsing for a particular episode.

## Current state

The existing checkpoint records inspection of the original concept without edits. This is independent design work, not an official Netflix feature or an integration with the service.

## Questions to resolve

- How does the viewer select eligible series or episodes?
- What happens when nothing eligible is available?
- How can a viewer skip, undo, or leave the random choice?
- What research supports the comfort-watching need and the proposed behavior?

No measured user outcomes or implemented playback behavior are claimed.
