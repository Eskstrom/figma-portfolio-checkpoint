# CMU Court Reservations

**Product design · Mobile + smartwatch · Refinement in progress**

[Visual project overview](https://eskstrom.github.io/projects/cmu-court-reservations/) · [Mobile design](https://www.figma.com/design/W1i2PizUUUvCtPx4EnxpFx/Sumukh-s-Space?node-id=4606-149) · [Watch prototype](https://www.figma.com/make/RGAbRr2RprARTQoGvNihJw/Smartwatch-App-Prototype)

## The problem and direction

Help someone move from finding a court to understanding, managing, and deliberately cancelling a reservation. Seven mobile frames separate discovery, time selection, review, confirmation, management, and cancellation. A smartwatch companion explores the same booking task in a smaller interaction space.

## Available evidence

The existing checkpoint records a verified watch path: Table Tennis → Today → 9 AM → Review → Confirm → loading → Confirmed → Manage → Cancel → confirmation → Cancelled. The booking count cleared after cancellation. This was a functional browser check, not a new user study.
