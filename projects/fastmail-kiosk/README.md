# FastMail Kiosk

**UX and interaction design · Interactive concept**

[Visual project overview](https://eskstrom.github.io/projects/fastmail-kiosk/) · [Figma Make prototype](https://www.figma.com/make/gc3I9jqgY0XMzbZ0SOaPKp/Fast-mail-Kiosk)

## The problem and direction

Guide a person through parcel shipping with understandable inputs, itemized costs, editable review, and recovery from an unsuccessful simulated payment. The ten-step journey covers welcome, address, dimensions, weight, handling, pickup, cost, review, payment, and confirmation.

## Documented checks

The version-5 checkpoint records required-field validation; required package, handling, collection, and speed choices; an estimate change from $19.99 to $29.99 when speed changes; review editing that preserves other selections; payment decline and retry; and a start-over dialog that preserves the order when dismissed and clears it when confirmed. Prices are synthetic examples.

Receipt language describes a concept handoff and does not promise email, postage, or tracking.

## Remaining work and limitations

Complete keyboard, responsive, and physical-kiosk accessibility checks. Functional checks are not user research or accessibility certification. No real payment, shipping, or tracking service is connected.
